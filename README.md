# CryptoBankPlus

CryptoBankPlus is a scalable, cloud-native platform for real-time, auto-scaling cryptocurrency transactions.

CryptoBankPlus is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoBankPlus.git`
2. `cd CryptoBankPlus`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure CryptoBankPlus, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
